This project was a simple implementation of a database, written in C++ that emphasized proper handling of memory on the heap. The database was organized as a linked list and sorted by an identification number unique to each record in the database.



<hr>

 This was the first project I had done in school that involved reading and writing data to dedicated save files, where the contents of a massive database created during a program’s runtime was converted into text and stored locally to be used in another session to load the same database. It was also my first time writing in C++ for a class, it helped me gain a better understanding of how programs store and retrieve information and gain an gain an appreciation for the strict typing of my variables which was not a habit that I needed when writing in python or javascript in my prior courses.  

Although the final project was a culmination of all the exercises that were done as homework which were individually easy, to get everything into a complex and dynamic database entailed its own challenges. This project in particular helped change my perspective on massive complex software as a collection of smaller simple modules interacting with each other. At the same time it reinforced to me the fragility of poor software design as it was possible to break the entire program if one module or class was implemented with improper error handling or allowed invalid data to pass.
